Quick start

Browse TMDB, click + Add, and within seconds a .strm file lands in your Jellyfin library that streams directly from TorBox or RealDebrid. No FUSE, no rclone, no local downloads.

Prerequisites

Docker + Compose One container. The image ships ARM64 and ARMv7 variants too.
TorBox account Essential plan or higher recommended. RealDebrid works as a fallback.
Jellyfin running Emby and Kodi read the same .strm files; Plex goes through Spore.

Run it

$ docker run -d \
-p 8088:8088 \
-v ./data:/data \
--name mycelium \
corveck/mycelium:latest
Or with Docker Compose:
$ git clone https://github.com/adamlippert/mycelium.git
$ cd mycelium
$ docker compose up -d
Open http://<your-host>:8088 — the setup wizard walks you through everything, and each step has a Test button. The first account you create becomes admin. No .env editing required.

Most settings are hot-reloadable via the Settings tab — only scheduler intervals need a restart. Full reference lives in .env.example.

TorBox rate limits

Two limits on POST /torrents/createtorrent, per IP:
60requests per hour
10requests per minute
In Catbox mode, createtorrent is only called on first playback — normal single-user usage stays well within the limits. All other endpoints: 5 req/s per IP.
Release filtering is a four-state rule model Seven categories — resolution, source, encode, visual tag, audio tag, audio channels, language — each with _PREFERRED / _EXCLUDED / _REQUIRED / _INCLUDED / _STRICT. Every category is evaluated against the full candidate pool independently, so the result never depends on rule order, and a dropped candidate always carries its reason. _INCLUDED overrides every other rule in every category — use it deliberately.
